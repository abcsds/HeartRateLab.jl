Part 1: HRV Measurement Theory

What is Heart Rate Variability?

Heart Rate Variability (HRV) quantifies the beat-to-beat variability in cardiac rhythm. Instead of a constant heartbeat, healthy hearts show natural variation in the time between consecutive beats.

Why HRV matters: - Reflects autonomic nervous system balance (parasympathetic vs sympathetic) - Indicator of cardiovascular health and fitness - Marker of stress, fatigue, and recovery - Clinical diagnostic tool for arrhythmias and neuropathy

4-Panel IBI Visualization

# Create comprehensive IBI visualization

           title="Inter-Beat Interval Time Series")

hlines!(ax1, mean(ibi_data), color=:coral, linestyle=:dash, linewidth=2)
band!(ax1, 1:length(ibi_data),
      fill(mean(ibi_data) - std(ibi_data), length(ibi_data)),
      fill(mean(ibi_data) + std(ibi_data), length(ibi_data)),
      color=(:steelblue, 0.2))

# Panel 2: IBI Distribution (Histogram)
ax2 = Axis(fig[1, 2], xlabel="IBI (ms)", ylabel="Count",
           title="IBI Distribution")
hist!(ax2, ibi_data, bins=40, color=(:coral, 0.7), strokewidth=1)

# Panel 3: Poincaré Plot
ax3 = Axis(fig[2, 1], xlabel="IBIₙ (ms)", ylabel="IBIₙ₊₁ (ms)",
           title="Poincaré Plot", aspect=DataAspect())
scatter!(ax3, ibi_data[1:end-1], ibi_data[2:end],
         markersize=5, color=(:purple, 0.5))
lims = extrema([minimum(ibi_data), maximum(ibi_data)])
lines!(ax3, [lims[1], lims[2]], [lims[1], lims[2]],
       color=:gray, linestyle=:dash, linewidth=2)

# Panel 4: Cumulative Distribution
ax4 = Axis(fig[2, 2], xlabel="IBI (ms)", ylabel="Cumulative Probability",
           title="Empirical CDF")

ecdf_vals = (1:length(sorted_ibis)) ./ length(sorted_ibis)

println("\nGenerating phase-space trajectories...")

fig = Figure(size=(1200, 800))

colors = [:blue, :red, :green]

for (idx, μ) in enumerate(param_values)
    ax = Axis(fig[div(idx-1, 2)+1, mod(idx-1, 2)+1],
              xlabel="Position", ylabel="Velocity",
              title="Van der Pol Phase Space (μ=$μ)")

    # Generate synthetic data
    params = (μ=μ, heart_rate=70.0)
    synthetic = simulate(vdp, params, 300)

    # Compute IBI differences (velocity proxy)
    velocity = diff(synthetic)

    # Plot phase space
    scatterlines!(ax, synthetic[1:end-1], velocity,
                  color=colors[idx], markersize=4,
                  linewidth=1.5, alpha=0.7)
end
